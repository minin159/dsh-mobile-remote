## 优1 · 桌面一键二维码入口（约 5–8 万，红线 6 万）

```text
任务：为 DSH 插件 mobile-remote 增加电脑端一键出码入口。工作目录 D:\dsh-plugins\mobile-remote。

范围（收紧）：
- 用 ctx.tools.register 注册工具 pair_qr（描述：手机扫码远程控制当前会话）：调用即在会话内
  渲染大尺寸二维码卡片（复用阶段 0 P6 的内联 qrcode-generator 生成逻辑），卡片附完整链接文本。
- 不做系统托盘、不做桌面快捷方式、不动设置页现有二维码。
- 服务端已有 /qr.svg 或 stateView.phone 则直接复用，无后端改动为优。

验收：电脑端调用工具出码 → 手机扫码进入页面可用；不开远程时工具不可见。
交付：版本 1.4.0；roadmap 记一行；commit + tag opt1-done。
```

## 优4 · 多设备观察者模式（约 15–25 万，红线 20 万）

```text
任务：为 mobile-remote 实现 1 主控 + N 观察者模式。工作目录 D:\dsh-plugins\mobile-remote。

范围（收紧）：
- 新连接默认「观察者」：只读看流（审批条/输入框隐藏，状态条标"观察中"）；当前无主控时
  可点「接管主控」升级；主控断开 30s 后任意观察者可接管。
- 观察者不可发消息/审批/切换绑定；顶替语义只作用于主控位（原"新连接顶替"仅对主控生效）。
- 审计记 observer_join/leave/takeover；最多 3 观察者（有界）。
- 不做观察者间通信、不做更细权限分级。

验收：两台设备（或手机+浏览器无痕窗）实测：观察者只读、接管生效、主控审批只有主控端出现。
交付：版本 1.7.0；commit + tag opt4-done。
```
