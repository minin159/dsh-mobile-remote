# 阶段 4 · UI 2.0：首页工作区卡片 + 会话视图对齐 ZCode

前置：阶段 2 完成（v1.1.0）。预算 15–25 万 token。
**范围不含底栏运行时控件**（盾牌/上下文/模型/思考强度 → 阶段 5 单独做）。

## 目标

移动端信息架构对齐 ZCode webRemoteControl（用户提供真机截图为视觉基准）：

1. **首页 = 工作区卡片长列表**（替换现在的"☰ 会话"平铺抽屉）：
   - 数据：`sessionQuery.listSessions()` 按 `header.cwd` 分组（P4 已证实带 cwd）；
     标题快照 `readTitleSnapshots` 沿用现有缓存（60s/单批 50）。
   - 卡片头：工作区名（cwd 末段）+ 完整路径 + 任务数 + 最近更新相对时间 + 展开/收起；
     页首汇总行「N 个工作区 · M 个任务」+ 刷新按钮 + 连接状态（"已连接到 DSH 实例"）。
   - 首次进入说明卡（一次性可关闭）："本次连接可以查看…失效后回到电脑端重新配对"。
   - **不做新建会话 "+"**：DSH 新建会话能力未探测，如实降级（记录在文档）。
2. **任务行**：标题截断 + 相对时间 + 四态状态胶囊（沿用阶段 2）+ 点击进入会话视图
   （复用 `POST /switch` 切换绑定 + 钉住语义）。
3. **会话视图**：
   - 顶栏：← 返回首页 + 当前会话标题。
   - 消息流增强：markdown **表格**渲染与行内代码 chip（受控 DOM 构建/textContent，
     防注入与阶段 2 代码块同标准）；流式期间悬浮"当前动作"toast（最新 tool/call 摘要，
     仿 ZCode「给出 token 与时间估算」pill）；新消息时出现"回到底部 ↓"FAB。
   - 审批条沿用阶段 1，不动。
4. **底部输入栏本阶段不动**：保持 输入框 + ↑发送 + 节流；五个扩展键位留给阶段 5。

- 附件 ＋（steer 纯文本，不值得动后端）；调色板主题切换（用户已否决，跟随系统保留）。
- 新建会话、云 relay、Bot Channel、phone-push 复用。
