## 探针（任务 5a）

  token 用量 / 上下文占用 / 缓存命中数据？

- **P9 思考强度档位**：harness 是否暴露 per-session/per-message 思考档位？

## 确定可实现项（无需探针）

- **盾牌 = 访问权限模式**：利用本插件自持的 approval handler，提供三档
  「手机审批（默认）/ 全部放行 / 全部拒绝」：
  - 全部放行 = 插件自动回 `'allowed-once'`（高危也放行，页面需红色警示条常驻）；
  - 全部拒绝 = 自动回 `'rejected'`；
  - 档位为**会话级临时状态**，重启回到手机审批；每次切换写审计 JSONL。
  - 电脑端同步提示（设置页状态行显示当前模式）。
- 底栏布局与交互按截图还原；↑ 发送沿用现有节流。
