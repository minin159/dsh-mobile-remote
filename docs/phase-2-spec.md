# 阶段 2 · 完整对齐 ZCode 功能面

前置：阶段 1 验收通过。预算 20–35 万 token。目标：补齐 ZCode webRemoteControl 的剩余产品面。

## 功能项（每项独立 commit，用户可当场裁剪）

1. **会话/工作区列表与切换**（依探针 P4 结论；不可枚举则如实降级为「最近会话」书签式切换）。
2. **状态标签**：会话列表项显示 运行中/空闲/完成/错误（`agent/status` + `agent/error`）。
3. **配对健壮性**：会话过期与重配对流程（对齐 ZCode 语义：过期需电脑端重新生成）、
   顶替互踢提示、页面失效原因文案（sessionNotFound/expired/kicked 等价物）。
4. **审计**：JSONL（`~/.dsh/mobile-remote-audit.jsonl`）记录每次连接/消息/审批
   （时间、动作、目标会话、来源、耗时）；设置页可开关。
5. **恢复加固**：长连接心跳、半开连接检测、弱网重连参数实测调优（配合 P5 数据）。
6. **UI 打磨**：消息流性能（虚拟滚动或截断）、代码块/工具调用渲染、暗色细节、错误态文案。

## 明确不做

- 云 relay、公网暴露（阶段 3 用户点名再说）；Bot Channel（飞书/微信/Telegram）。
- 任何与 phone-push 的代码/配置/审计文件复用。

## 验收

- 手机端：列表切换、状态刷新、过期重配对、审计文件可回溯。
- 电脑端：不开远程零影响回归。
